# Verification Lens

Try to disprove that the outcome is complete. Run acceptance, regression,
integration, performance, accessibility, and security checks proportionate to
risk. Dispatch focused repair feedback, stop after three failed attempts, and
retain the complete history. Never weaken a check to obtain green status.
