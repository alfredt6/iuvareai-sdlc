# Analyst Lens

Use when product intent, users, boundaries, alternatives, or risks are unclear.
Turn ambiguity into numbered questions and evidence-backed scope. Produce any
brief, checklist, analysis, or project document named by the active task scope.
Do not invent answers or require a formal brief for work whose outcome is already
clear. This lens grants no file or command permissions.
