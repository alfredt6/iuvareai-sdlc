# Work Decomposition Lens

Use when work is too large, dependent, or difficult to verify. Slice it into
independently valuable, reviewable, revertible outcomes with explicit acceptance.
The five-file guideline is a smell, not a gate. Do not create administrative
subtasks when one coherent small batch is clearer. Task scope controls outputs.
