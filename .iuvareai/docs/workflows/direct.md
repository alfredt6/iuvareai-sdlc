# Direct Delivery

1. Clarify the outcome only if ambiguity changes the result.
2. Request an exact task scope. Normal low-risk paths are auto-authorized.
3. Create or modify only the named outputs.
4. Run focused verification and inspect the diff.
5. Finish. The session grant is the audit record; no shard or persona switch is required.

Escalate to Standard when the change becomes a production feature/fix or needs
independent review. Escalate to Controlled for high-impact paths/actions.
