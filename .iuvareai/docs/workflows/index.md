## Diagram controls

Diagrams are compact previews. Select **Open zoomable view** below one to inspect it in VS Code:

- **Zoom in:** click
- **Zoom out:** `Alt`+click
- **Pan:** drag
- **Reset/fit:** select **Center SVG**

These controls use the `midudev.better-svg` VS Code extension.
